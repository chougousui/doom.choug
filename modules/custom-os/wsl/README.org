#+title: :custom-os wsl

* Description
wslg环境下一些需要手动处理的问题

1. 图标问题: 打开emacs后,doom首页的图标问题可以在emacs内运行 =M-x nerd-icons-install-fonts= 来解决,该命令安装的字体为 =Symbols Nerd Font Mono=,也可以使用系统工具安装该字体
2. 窗口边框问题: =(add-to-list 'default-frame-alist '(undecorated . t))= 可以告诉GTK不要绘制边框,但会导致没有抓手来移动窗口,也可以在GTK里面配置边框的高度:
   #+begin_src css
   /* ~/.config/gtk-3.0/gtk.css */
   .default-decoration {
     min-height: 0;
     padding: 0px;
   }
   .default-decoration .titlebutton {
     min-height: 1px;
     min-width: 0px;
   }
   #+end_src
   可以在emacs内运行 =M-x emacs-version= 来确认GTK版本
3. 复制内容无法粘贴到宿主机: 从WSLg应用Emacs中复制的内容无法粘贴到宿主机上,而同为WSLg应用的Chromium一切正常.原因是Emacs在选区变化时会把选区写入PRIMARY,GTK3写PRIMARY时会先清空与CLIPBOARD共用的对外"可粘贴格式表",而WSLg不支持PRIMARY,导致该表无法重新登记.
   =(setq select-active-regions nil)= 让Emacs不再把选区写入PRIMARY即可避开.出于个人偏好,该设置已写在 =choug= 模块的 =config.el= 中,本模块不再重复设置
