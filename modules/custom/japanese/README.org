#+title:    :custom japanese
#+subtitle: 通过 liberime 使用 Kagiroi 日语输入

* Description :unfold:
该模块为 Emacs 内部的 Kagiroi schema 实现一个独立、轻量的日语输入前端，并复用现有的 =liberime= 连接层。

输入链路如下：

1. 模块使用 =register-input-method= 注册名为 =kagiroi= 的自定义 Emacs 输入法，并负责 composition、候选显示和输入法启停。
2. 前端通过 =liberime-process-event= 将 Emacs 输入事件直接传给 =liberime=。
3. 激活输入法时，=liberime= 加载并选择 =kagiroi= schema，再由进程内的 =librime= 和 =librime-lua= 完成罗马字、假名及汉字转换。
4. Kagiroi schema 来自 [[https://github.com/rimeinn/rime-kagiroi][rimeinn/rime-kagiroi]]，其运行文件保存在专供 Emacs 使用的 =liberime-user-data-dir= 中。

模块依赖 =:input (chinese +rime)= 和 =:custom chinese-ext=。当前的 =liberime-user-data-dir= 为 =~/.config/my-rime-schema-for-emacs/=。

** Module flags
- +childframe ::
  使用 =posframe= 在 child frame 中显示 preedit 和候选；child frame 不可用时回退到 echo area。

** Packages
- [[doom-package:posframe]]，启用 [[doom-module:+childframe]] 时安装

* Installation
Kagiroi 依赖 =librime >= 1.11.2= 和 =librime-lua=。

克隆 [[https://github.com/rimeinn/rime-kagiroi][rimeinn/rime-kagiroi]]，然后将 schema 文件复制到 =~/.config/my-rime-schema-for-emacs/=，但不要复制：

- =default.yaml=：会替换现有的 Rime 全局配置。
- =key_bindings.yaml= 和 =punctuation.yaml=：名称通用，可能与其他 schema 冲突，并且当前配置不需要它们。
- =build/=：其中的编译产物不能在不同 Rime 环境之间混用。
- 项目文档、开发工具、测试及项目元数据：这些都不是运行文件。

=kagiroi_custom_phrases.txt= 是可选文件。

在 =default.custom.yaml= 中加入 Kagiroi，同时保留已有 schema：

#+begin_src yaml
patch:
  schema_list:
    - { schema: kagiroi }
#+end_src

随后执行 =M-x liberime-deploy=。

Kagiroi 的部分词典文件较大。安装后的第一次 Emacs 启动中，=liberime= 会进行初次部署，期间可能暂时卡住，需要等待部署完成。

* Usage
执行 =M-x +japanese/toggle-kagiroi=，或使用 Emacs 的输入法选择命令：

#+begin_example
M-x set-input-method RET kagiroi RET
#+end_example
